# CoE regional map data

The static land paths are derived from Natural Earth 1:110 million land polygons, a public-domain physical-geography dataset. No mapping library or network request runs in the browser.

- Source: https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/
- Terms: https://www.naturalearthdata.com/about/terms-of-use/
- Source GeoJSON: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson
- Retrieved: 2026-10-16. Source SHA-256: `9e0729ee253ca7d7a5c4ae9395fb1902264c5377c52e224d13dd85010e2835d9`.

The source is projected with Natural Earth I into an 800 × 440 view box and rounded to two decimals. Polygons wholly south of 60°S are omitted. Marker positions are illustrative and do not assert actual company locations. The location and path JSON files are the approved static rendering inputs; the original source data and generation records remain in the private approved design archive.
