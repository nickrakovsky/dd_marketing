## How to read this ledger

- CSV record counts the header as record 1. A quoted multiline query is one CSV record, so this is not a physical text-file line number.
- Query spelling is retained; line breaks and repeated whitespace are collapsed only for display. Exact raw text remains in the source CSV.
- Each query receives one primary group. The groups are analyst judgements, not Search Console categories or validated user intentions; Q IDs are unrelated to the earlier L meaning IDs.
- Specific task generally takes precedence over industry: picking in healthcare/pharmacy remains Q09. Explicit software/WMS goes to Q13, bonded/provider wording to Q15, and dock/yard wording to Q14. The original wording preserves the other modifiers.
- Q03 does not establish a non-audit purpose; Q04 does not establish everyday-use intent. Q06 inspection purpose remains open. Q08 stock audit may concern operational, financial or other assurance.
- Q12 combines several specialist contexts for bookkeeping; they are not one proposed page. Q15 combines provider and bonded matters for bookkeeping; bonded reconciliation is not assumed to be supplier selection.
- Flags: **format** = explicit form/template/file/download wording; **prompt-shaped** = selected conversational or imperative forms; **uncertain** = selected unclear/context-poor queries. Flags overlap and are not additive groups; their absence does not establish certainty.
- Instructions embedded in query strings are recorded as data only. Their stated locations are not verified geography. Prompt-shaped syntax does not identify a search product or the origin of the query.
- CTR and position in the record table are as exported. Aggregate CTR below is total clicks / total impressions; aggregate position is an approximate impression-weighted average of the rounded query positions.
